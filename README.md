# Data-Driven Logistics Optimization

## Project Overview

This project applies data science techniques to improve logistics
and supply chain operations for a regional distribution company.

## Objectives

- Reduce inventory stockouts
- Improve on-time delivery
- Reduce delivery cost
- Shorten fulfillment time
- Optimize delivery routes

## Techniques Used

- Data Cleaning
- Exploratory Data Analysis
- Random Forest Regression
- Demand Forecasting
- K-Means Clustering
- Vehicle Routing Optimization
- KPI Analysis

## KPIs

- Inventory Turnover Ratio
- On-Time Delivery Rate
- Cost per Delivery
- Order Fulfillment Cycle Time
- Stockout Rate

## Project Workflow

Data Collection
→ Data Cleaning
→ EDA
→ Feature Engineering
→ Demand Forecasting
→ Delivery Zone Clustering
→ Route Optimization
→ KPI Evaluation

## Technologies

Python, Pandas, NumPy, Scikit-learn,
Matplotlib, Google OR-Tools, Jupyter Notebook
